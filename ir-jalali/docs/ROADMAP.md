# IR-Jalali — Roadmap

## ✅ Milestone 1 — Foundation (کامل)

- معماری هسته: Kernel / DI / Config / Http / Database / Events / Hooks
- ۴۸ جدول با مایگریشن دودرایوری (MySQL/SQLite) + سیدر
- نصب‌کننده وب + ویزارد راه‌اندازی با حالت‌های سایت + قفل نصب
- احراز هویت + RBAC (۶ نقش، ۲۷ دسترسی) + محدودیت نرخ + ممیزی
- تقویم جلالی Pure-PHP + abstraction تقویم (آماده میلادی/قمری)
- چندزبانه (fa_IR/en_US) + RTL
- مدیریت رسانه امن + زمان‌بند + صف + کرون + انتشار زمان‌بندی‌شده
- لاگ چندکاناله + حسابرسی + لاگ امنیتی

## ✅ Milestone 2 — Engines & Builder (کامل)

- موتور قالب: `ThemeManager` + `theme.json` + زنجیره قالب/فرزند + رندر فرانت
- موتور افزونه: نصب/فعال‌سازی/غیرفعال/حذف، وابستگی، قابلیت‌ها، مایگریشن افزونه
- بیلدر بصری: بلاک‌ها/ویجت‌ها + ثبت بلاک و ویجت توسط افزونه + کاتالوگ
- فیلدساز + انواع محتوای سفارشی (CPT) از ادمین
- منوساز + فرم‌ساز + بازبینی‌ها + موتور قالب‌های صفحه
- بازارچه: معماری آماده، کاتالوگ محلی، بسته‌بندی، اسکن امنیتی، آپدیت یک‌کلیکی با بکاپ/رولبک
- مجوزها (licensing) + SDK توسعه‌دهنده (`IRJalali::for()`) + سازنده‌های `make:plugin/theme/block`
- REST API نسخه ۱ با توکن و Throttle
- کش: درایور فایل + درایور Redis اختیاری با افتادن خودکار

## ✅ Milestone 3 — Modules & Scale (کامل)

- ۱۳ ماژول رسمی به‌صورت افزونه (بدون تغییر هسته):
  فروشگاه، رزرواسیون، عضویت، آموزش، دایرکتوری، سئو، آمار، ایمیل، کش، امنیت،
  **PWA** (`ir-pwa`: مانیفست + سرویس‌ورکر + آفلاین + نصب روی موبایل) و
  **انتقال محتوا** (`ir-transfer`: خروجی/ورودی JSON + کلون کامل سایت) + نمونه مرجع
- بازارچه محلی با ۱۴ بسته نصبی
- پشتیبان‌گیری/بازیابی کامل سایت + گزارش سلامت سیستم
- پالت فرمان در ادمین (Ctrl/Cmd+K) + نوتیفیکیشن‌ها
- وایت‌لیبل: نام/لوگو/پاصفحه اختصاصی پنل مدیریت از تنظیمات
- تست‌های خودکار هسته + تست یکپارچگی ۱۴ افزونه + بررسی زندهٔ وب واقعی

## ◻️ بعدی (پیشنهادی)

- چندزبانگی محتوا (ترجمه پست‌ها) و چندسایتی کامل
- درگاه پرداخت آنلاین (وابسته به کلیدهای بیرونی — معماری آماده با `ir_commerce`)
- آزمون‌های مرورگری خودکار (CI)
